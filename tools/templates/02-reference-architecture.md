## ۲-۳. قالب استاندارد رویداد (Event Envelope)

همهٔ رویدادهای ستون فقرات باید این قالب را رعایت کنند؛ Schema Registry آن را اعتبارسنجی می‌کند.

```json
{
  "event_id": "01J9Z8X7K2M3N4P5Q6R7S8T9V0",
  "event_type": "material.consumed",
  "schema_version": "1.2.0",
  "occurred_at": "2026-10-03T08:14:22.415Z",
  "ingested_at": "2026-10-03T08:14:22.902Z",
  "source": {
    "system": "MES",
    "site": "THR-01",
    "instance": "mes-prod-01",
    "device_id": null
  },
  "actor": {
    "type": "user",
    "id": "EMP-00431",
    "roles": ["line_operator"],
    "authn": "sso"
  },
  "entity": {
    "type": "batch",
    "id": "B-14040711-03",
    "keys": { "work_order": "WO-14040711-0012", "line": "THR-PRD-LN1", "product": "GTIN-6260000000013" }
  },
  "correlation_id": "01J9Z8X0000000000000000000",
  "causation_id": "01J9Z8W9A1B2C3D4E5F6G7H8J9",
  "payload": {
    "material": "GTIN-6260000000099",
    "material_batch": "RM-14040701-A2",
    "qty": 1240.5,
    "uom": "kg",
    "bin": "RM-Z1-A03-R12-B4",
    "weighed_by": "SCALE-LN1-01",
    "quality_status": "released"
  },
  "meta": {
    "idempotency_key": "MES:material.consumed:WO-14040711-0012:RM-14040701-A2:1240.5",
    "severity": "info",
    "retention_class": "operational_7y",
    "pii": false
  },
  "signature": "sha256:9f2b...c41d"
}
```

**قواعد اجباری:**
- `event_id` ULID (قابل مرتب‌سازی زمانی، بدون نیاز به هماهنگی مرکزی) — امکان کار آفلاین.
- `idempotency_key` برای جلوگیری از ثبت مضاعف هنگام تلاش مجدد (Retry/Offline Replay).
- `correlation_id` یکتا برای هر «زنجیرهٔ فرآیند» (مثلاً یک دستور کار از صدور تا ترخیص).
- `causation_id` رویدادی که این رویداد را به‌وجود آورده (ساختار علّی برای ممیزی).
- همهٔ زمان‌ها **UTC**؛ نمایش با تقویم شمسی و منطقهٔ زمانی محلی در لایهٔ نمایش.
- `signature` بخشی از زنجیرهٔ درهم‌سازی: `hash = SHA256(prev_hash + canonical_json(event))`.

### ۲-۴-۲. درخت موضوع MQTT/Sparkplug B

```
spBv1.0/THR1/<GROUP>/<MESSAGE_TYPE>/<EDGE_NODE>/<DEVICE>
نمونه: spBv1.0/THR1/PRD-LN1/DDATA/MXR-Gateway/MXR-M01

Kafka topics (سطح L3/L4):
  ot.<area>.<line>.telemetry       سری‌زمانی فشرده
  ot.<area>.<line>.events          رویدادهای وضعیت/توقف/آلارم
  mes.workorder.*                  صدور/شروع/اتمام/تأیید دستور کار
  mes.batch.*                      تولد/تغییر وضعیت/ترخیص بچ
  wms.<site>.movement.*            رسید/جابجایی/برداشت/ارسال
  qms.ncr.* / qms.capa.*           عدم انطباق و اقدام اصلاحی
  cmms.workrequest.* / cmms.wo.*   درخواست کار و دستور کار
  hse.ptw.* / hse.incident.*       مجوز کار و حادثه
  hr.attendance.* / hr.competency.*حضور و صلاحیت
  fin.posting.*                    رویداد مالی (از هر واحد)
  audit.trail                      همهٔ رویدادها (تغییرناپذیر)
```

`GROUP`ها با زون‌های امنیتی هم‌راستا می‌شوند تا کنترل دسترسی در سطح موضوع (Topic-Level ACL) ممکن باشد.
