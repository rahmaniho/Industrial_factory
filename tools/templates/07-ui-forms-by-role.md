## ۷-۳. صفحات خارج از سازمان و میدانی

| صفحه | کاربر | محتوا | ملاحظه |
|---|---|---|---|
| پورتال کارمند | R18 | فیش حقوق، مرخصی، کارکرد، دوره‌ها، گواهی‌ها، درخواست‌ها | موبایل-نخست، دسترسی فقط به دادهٔ خود |
| پورتال مشتری | R19 | ثبت سفارش، پیگیری، فاکتور، COA، مرجوعی، مانده حساب | احراز قوی + تفکیک دادهٔ مشتریان |
| پورتال تأمین‌کننده | R19 | ASN، وضعیت PO، فاکتور، ارزیابی عملکرد | فقط دادهٔ همان تأمین‌کننده |
| اپلیکیشن موبایل مدیران | R16/R20/R21 | شاخص‌های کلیدی + تأییدهای ضروری | تأیید با MFA |
| فرم‌های میدانی (آفلاین) | R07/R09/R05 | چک‌لیست، PTW، شمارش، رخداد | آفلاین-نخست با صف محلی ۷۲ ساعته |

## ۷-۴. اصول طراحی رابط کاربر (UX) برای محیط صنعتی

| اصل | الزام مشخص |
|---|---|
| **دستکش‌پذیر و نویزپذیر** | اهداف لمسی ≥ ۴۴ پیکسل؛ کنتراست بالا؛ فونت خوانا در نور سوله |
| **حداکثر ۳ کلیک برای کارهای تکراری** | ثبت توقف: انتخاب علت از درخت ۳ سطحی + تأیید |
| **عدم وابستگی به تایپ** | استفاده از بارکد/QR/دکمه‌های بزرگ به‌جای ورود متن |
| **بازخورد فوری** | هر اسکن/ثبت، بازخورد صوتی/لرزشی/بصری در کمتر از ۳۰۰ میلی‌ثانیه |
| **RTL و فارسی واقعی** | تقویم شمسی، اعداد و واحدها، چیدمان آینه‌ای، فونت‌های فارسیِ خوانا |
| **حالت آفلاینِ شفاف** | نشان وضعیت اتصال همیشه نمایان؛ صف محلی با تعداد در انتظار |
| **خطاهای قابل‌فهم** | پیام خطا باید «چه باید کرد» بگوید، نه کد خطا |
| **سلسله‌مراتب آلارم** | آلارم بحرانی همیشه بالای همه و غیرقابل‌پوشاندن |
| **طراحی برای غبار/رطوبت/ضربه** | تبلت‌های IP65 با قاب، پایه و بند |
| **سادگیِ عامدانه** | صفحهٔ اپراتور نباید بیش از ۵ تا ۷ عنصرِ اصلی داشته باشد |
