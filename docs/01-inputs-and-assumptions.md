# ۱. ورودی‌ها، مفروضات و دامنه (Inputs & Assumptions)

تمام پارامترهای ورودیِ پرامپت خالی بوده‌اند؛ طبق دستور، فرض‌های منطقی با برچسب **[فرض]** ثبت شده‌اند.
هر فرض باید تا پایان فاز ۰ با دادهٔ واقعی جایگزین شود (ستون «روش تأیید»).

## ۱-۱. پارامترهای ورودی

| پارامتر | مقدار فرضی | برچسب | روش تأیید (فاز ۰) |
|---|---|---|---|
| نوع صنعت | فرآورش غذاییِ **بچ‌محور** (۳ خط: آماده‌سازی، پخت/فرآیند، بسته‌بندی) با الزامات بهداشتی بالا | [فرض] | بازدید میدانی + لیست محصولات |
| ظرفیت تولید | ۱۲۰ تن محصول در روز (۴۰ تن/خط/روز)، ۳۶٬۰۰۰ تن/سال (۳۰۰ روز کاری) | [فرض] | دادهٔ ۱۲ ماههٔ فروش/تولید |
| تعداد شیفت | ۳ شیفتِ ۸ ساعته، ۲۴/۷ (به‌جز توقف‌های برنامه‌ریزی‌شده PM) | [فرض] | قراردادهای کاری + برنامهٔ تولید |
| تعداد پرسنل | ۴۵۰ نفر: ۳۲۰ تولید · ۴۵ نگهداشت · ۳۰ QC/آزمایشگاه · ۵۵ ستاد (ستادی: مالی/HR/بازرگانی/IT/حراست) | [فرض] | فایل پرسنلی HR |
| وضعیت فعلی | **نیمه‌اتومات**: PLCهای قدیمی (Siemens S7-300، چند Modbus RTU)، ۲ خط دارای HMI محلی،**بدون MES**، ERP جزئی (مالی + انبار سنتی)، ثبت کاغذی در QC و نت | [فرض] | ممیزی فنی تجهیزات + نقشهٔ شبکه |
| الزامات قانونی | ISO 9001، ISO 14001، ISO 45001، HACCP، FSSC 22000؛ الزامات مالیاتی/بیمه/گمرکیِ جاری | [فرض] | گواهی‌نامه‌ها + نظر مشاور انطباق |
| زبان و منطقه | فارسی (RTL) پیش‌فرض + انگلیسی + عربی؛ تقویم شمسی؛ واحد SI + واحدهای محلی (تن، کیلوگرم)؛ چندارزی (ریال/تومان، USD، EUR) | [فرض] | مصاحبه با ذی‌نفعان |
| محدودهٔ جغرافیایی | یک سایت تولیدی + یک انبار محصول خارج از سایت | [فرض] | — |
| افق برنامه‌ریزی | ۳۰ ماه اجرا + ۵ سال بهره‌برداری | [فرض] | — |

## ۱-۳. دامنه (In-Scope / Out-of-Scope)

**در دامنه:**
۱۴ واحد عملیاتیِ تعریف‌شده در [`03-units/`](03-units/) · زیرساخت شبکه/سرور/اتاق کنترل ·
Historian · MDM · ستون فقرات رویداد · BI · امنیت OT/IT تا سطح IEC 62443 SL-2 (هدف: SL-3 برای زون‌های بحرانی) ·
آموزش و مدیریت تغییر.

**خارج از دامنه (اما پیش‌نیاز/مرتبط):**
- بازطراحی فرآیندهای کسب‌وکار (BPR) فراتر از آنچه اتوماسیون اقتضا می‌کند
- تعویض کامل ماشین‌آلات فرآیندی (فقط retrofit ابزار دقیق و کنترل)
- انتخاب/جایگزینی ERP در صورت عدم وجود API (در [`16-open-questions.md`](16-open-questions.md) مطرح شده)
- ساختمان و تأسیسات عمرانی (به‌جز BMS و پایش)
- امنیت فیزیکی فراتر از حراستِ تعریف‌شده (حفاظت محیطی/فنس‌کشی)

## ۱-۴. واژه‌نامه و کدهای اختصاری

| اختصار | معادل فارسی | توضیح کوتاه |
|---|---|---|
| MES | سامانهٔ اجرای تولید | مدیریت دستور کار، شجره‌نامه، OEE |
| MOM | مدیریت عملیات تولید | umbrellaی MES/QMS/WMS/CMMS |
| LIMS | سامانهٔ مدیریت آزمایشگاه | نمونه، آزمون، نتیجه، تأیید |
| WMS | سامانهٔ مدیریت انبار | مکان‌محور، لایه‌ای، اسکن‌محور |
| CMMS/EAM | سامانهٔ نگهداشت / مدیریت دارایی | درخت دارایی، PM، PdM |
| MDM | مدیریت دادهٔ پایه | Single Source of Truth |
| Historian | پایگاه دادهٔ سری‌زمانی | دادهٔ فرآیندی با برچسب زمان |
| PTW | مجوز کار (Permit to Work) | گرم/ارتفاع/فضای بسته/برق |
| LOTO | قفل‌گذاری/برچسب‌گذاری | Lockout/Tagout |
| OEE | اثربخشی کلی تجهیز | A × P × Q |
| FPY | بازده اولین بار | بدون دوباره‌کاری |
| OTIF | تحویل به‌موقع و کامل | On Time In Full |
| SSCC | کد سریال واحد حمل (GS1) | شناسهٔ پالت |
| FEFO/FIFO | انقضا/ورود — اولین خارج‌شود | قاعدهٔ برداشت |
| ATP | موجودی قابل تعهد | Available-to-Promise |
| SIL | سطح یکپارچگی ایمنی | IEC 61508/61511 |
| DMZ | منطقهٔ غیرنظامی | جداسازی OT/IT |
| RACI | مسئول/پاسخگو/مشورت/مطلع | ماتریس نقش‌ها |
| RPO/RTO | نقطهٔ بازیابی زمان/داده | DR |
