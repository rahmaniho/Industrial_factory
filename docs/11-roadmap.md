## ۱۱-۶. سنجه‌های پیشرفت هر فاز (Gate Review)

فازی «تمام» است که معیارهای زیر همگی تأیید شوند؛ در غیر این صورت ورود به فاز بعد ممنوع است.

| فاز | معیار خروج |
|---|---|
| فاز ۰ | ≥ ۹۵٪ اقلام کلاس A در MDM تعریف و تأیید شده؛ مالکان داده منصوب؛ نقشهٔ شکاف مصوب |
| فاز ۱ | شبکه OT/IT تفکیک‌شده؛ Historian با ≥ ۹۵٪ تگ‌های برنامه‌ریزی‌شده؛ SSO/MFA فعال؛ DMZ مستند |
| فاز ۲ | خط پایلوت با OEE خودکار و انحراف زیر ۲٪ از محاسبهٔ دستی؛ آلارم‌ها استانداردسازی‌شده |
| فاز ۳ | ≥ ۹۰٪ ثبت‌های تولید خودکار؛ قرنطینهٔ کیفی فعال؛ WOهای PM خودکار؛ مغایرت موجودی < ۲٪ |
| فاز ۴ | ≥ ۸۵٪ اسناد مالی خودکار؛ بهای واقعی هر بچ محاسبه‌شده؛ انحراف بهای تمام‌شده < ۳٪ |
| فاز ۵ | داشبوردها با تعریف واحد شاخص‌ها؛ زنجیرهٔ سرد و انرژی پایش‌شده؛ مانور فراخوان < ۳۰ ثانیه |
| فاز ۶ | آموزش ≥ ۹۵٪ کاربران؛ دو مانور DR موفق؛ مستندات و Runbook تحویل‌شده |
