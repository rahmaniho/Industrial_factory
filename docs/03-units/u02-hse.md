# واحد ۲ — ایمنی، بهداشت و محیط‌زیست (HSE)

| مشخصه | مقدار |
|---|---|
| کد واحد | **HSE** |
| سطوح Purdue | L0 (دتکتور گاز/حریق/دوش اضطراری) · L1 (Safety PLC) · L2 (پنل اعلام حریق، HMI ایمنی) · L3 (سامانهٔ HSE) |
| سامانهٔ نگه‌دار | HSE Suite (PTW، رخداد، بازرسی، MSDS، پسماند) + Fire Alarm + Gas Detection + EHS Analytics |
| وابستگی‌های بحرانی | حراست (تخلیه)، نت (LOTO)، تولید (توقف ایمن)، انبارها (مواد شیمیایی) |
| سطح ایمنی عملکردی | **SIL 2** برای زون‌های فرآیندی، **SIL 3** برای سیستم اطفای گازی و قطع اضطراری بحرانی (تعیین نهایی پس از HAZOP/LOPA) |
| الزام انطباق | ISO 45001، ISO 14001، مقررات ملی ایمنی و محیط‌زیست |

## الف) مأموریت و دامنه

**مأموریت:** پیشگیریِ سیستمی از حادثه، بیماری شغلی و آسیب محیطی؛ و تبدیلِ «انطباق» از یک
فعالیتِ اداری دوره‌ای به یک **ویژگیِ درونیِ سیستم** (Compliance by Design).

**در دامنه:** شناسایی خطر · مجوز کار (PTW) · LOTO · پایش گاز و حریق · رخداد/شبه‌حادثه ·
بازرسی · آموزش ایمنی · MSDS · پسماند · پایش زیست‌محیطی · PPE · واکنش اضطراری.

**خارج از دامنه:** ایمنی محصول (در QC)، امنیت فیزیکی (در حراست)، ایمنی سایبری (در NFR).

## ب) فرآیندهای اصلی

| # | فرآیند | تریگر | خروجی | سطح اتوماسیون |
|---|---|---|---|---|
| P1 | شناسایی خطر و ارزیابی ریسک (JSA/HIRA) | کار جدید/تغییر/حادثه | ماتریس ریسک + کنترل‌ها | گردش‌کار + نسخه‌بندی |
| P2 | مجوز کار (PTW) | درخواست کار گرم/ارتفاع/فضای بسته/برق/حفاری | مجوز با زنجیرهٔ تأیید + پنجرهٔ زمانی | کاملاً الکترونیکی |
| P3 | قفل‌گذاری/برچسب‌گذاری (LOTO) | نیاز به کار روی تجهیز انرژی‌دار | طرح قفل‌گذاری + تأیید تصویری + قفل فیزیکی/الکترونیکی | الکترونیکی با راستی‌آزمایی |
| P4 | پایش پیوستهٔ گاز | افزایش غلظت | آلارم محلی + تهویهٔ خودکار + قطع منبع | کاملاً خودکار |
| P5 | اعلام و اطفای حریق | دتکتور/شستی | آلارم آدرس‌پذیر + نقشهٔ زندهٔ تخلیه + اطفا | کاملاً خودکار |
| P6 | گزارش حادثه/شبه‌حادثه | وقوع/مشاهده | پرونده + ریشه‌یابی (RCA) + CAPA | الکترونیکی، موبایلی |
| P7 | بازرسی و پایش دوره‌ای | برنامه (روزانه/هفتگی/ماهانه) | چک‌لیست + انطباق + اقدام اصلاحی | موبایل آفلاین-نخست |
| P8 | مدیریت مواد شیمیایی و MSDS | ورود مادهٔ جدید | برگهٔ ایمنی + قواعد نگه‌داری + ناسازگاری‌ها | خودکار از تأمین‌کننده |
| P9 | مدیریت پسماند | تولید پسماند | ردیابی وزن/نوع/مقصد + مانیفست | خودکار با ترازو |
| P10 | آموزش و صلاحیت ایمنی | الزام نقش | ماتریس آموزش + گواهی دیجیتال | یکپارچه با HRM |
| P11 | واکنش اضطراری و تخلیه | آلارم بحرانی | فراخوان + نقشهٔ حضور + گزارش تخلیه | خودکار |

**سناریوی PTW (P2):** تکنسین مکانیک برای تعویض یاتاقان پمپ P-104 درخواست «کار گرم» می‌دهد
→ سیستم به‌طور خودکار بررسی می‌کند: (۱) آیا دستور کار CMMS باز است؟ (۲) آیا LOTO مرتبط ثبت شده؟
(۳) آیا گواهی جوشکاری تکنسین معتبر است؟ (۴) آیا PTW کار گرمِ دیگری در شعاع ۱۵ متری فعال است (تداخل)؟
(۵) آیا پایش گازِ منطقه در ۳۰ دقیقهٔ گذشته «سالم» بوده؟ → ۴ شرط اول برقرار، شرط ۵ خیر
⇒ سیستم درخواست را **تا دریافت قرائت گازِ معتبر نگه می‌دارد** و یک وظیفهٔ «اندازه‌گیری گاز» برای
HSE ایجاد می‌کند. کل این زنجیره در Audit با `correlation_id` یکتا ثبت می‌شود.
