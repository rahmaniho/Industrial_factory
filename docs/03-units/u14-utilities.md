# واحد ۱۴ — تأسیسات (Utilities)

| مشخصه | مقدار |
|---|---|
| کد واحد | **UTL** |
| زیرمجموعهٔ | MNT (همان CMMS) اما با نقش «تأمین‌کنندهٔ خدمت» برای کل کارخانه |
| سطح Purdue | L0 (ترانسمیترها، آنالایزرها، کنتورها) · L1 (PLC تأسیسات/BMS) · L2 (SCADA تأسیسات) |
| سامانهٔ نگه‌دار | BMS/SCADA تأسیسات + CMMS + سیستم مدیریت انرژی (EMS) |
| ویژگی متمایز | این واحد هم «نگهداشت» است و هم «تولیدِ خدمت»؛ شاخص‌های آن مستقیماً در بهای تمام‌شده می‌نشینند |

---

## الف) مأموریت و دامنه

**دامنه (الف):** بویلر و سیستم بخار · چیلر و برج خنک‌کن · هوای فشرده · تصفیهٔ آب (RO/DI/نرم‌سازی) ·
سیستم HVAC و تهویهٔ صنعتی · سیستم آتش‌نشانی و پمپ‌های آتش‌نشانی · فاضلاب و تصفیه‌خانه ·
نیتروژن و گازهای فرآیندی · دیزل ژنراتور اضطراری · توزیع آب و شبکهٔ تأسیساتی.

## ج) داده‌های پایه (Master Data)

| موجودیت | کلید | مالک | توضیح |
|---|---|---|---|
| دارایی تأسیساتی | `util_asset_id` | تأسیسات | بویلر، چیلر، کمپرسور، پمپ، مخزن، برج |
| نقطهٔ اندازه‌گیری | `util_point_id` | تأسیسات | نوع (دما/فشار/دبی/سطح/کیفیت)، واحد، آستانه‌ها |
| خدمت تأسیساتی | `utility_service_id` | تأسیسات | بخار، آب سرد، هوا، آب RO، نیتروژن |
| نرخ/بهای خدمت | `utility_rate_id` | مالی + تأسیسات | هزینهٔ هر واحد خدمت (برای تخصیص به محصول) |
| مراکز مصرف | `consumer_id` | تأسیسات + تولید | مرکز هزینه/خط/تجهیز مصرف‌کننده |
| کیفیت آب و استاندارد | `water_spec_id` | QC + تأسیسات | پارامترها و حدود برای هر کاربرد |
| برنامهٔ نمونه‌برداری/آزمون | `util_sample_id` | QC | نقاط، تناوب، آزمون‌ها |
| ست‌پوینت‌های بهینه | `setpoint_id` | تأسیسات | مقادیر هدف به تفکیک فصل/بار |
| پارامتر زیست‌محیطی | `env_param_id` | HSE | حدود مجاز خروجی، روش اندازه‌گیری |
| مجوزهای قانونی | `permit_env_id` | HSE | حدود تخلیه، تناوب گزارش‌دهی |

## ح) شاخص‌های کلیدی (KPI)

| KPI | فرمول | هدف | منبع داده | فرکانس |
|---|---|---|---|---|
| مصرف ویژهٔ برق | `kWh / تن محصول` | ≤ ۹۵ | EMS + MES | ماهانه |
| مصرف ویژهٔ بخار | `تن بخار / تن محصول` | کاهش ۱۰٪ | فلومتر + MES | ماهانه |
| مصرف ویژهٔ آب | `m³ آب / تن محصول` | کاهش ۱۵٪ | کنتور + MES | ماهانه |
| هزینهٔ خدمات به‌ازای تن | `هزینهٔ بخار+هوا+آب+برق / تن محصول` | کاهش ۱۲٪ | ERP + EMS | ماهانه |
| راندمان بویلر | `انرژی خروجی بخار / انرژی ورودی سوخت × 100` | ≥ ۸۵٪ | محاسبه از اندازه‌گیری | ماهانه |
| راندمان چیلر (kW/ton) | `kW برق / تن تبرید` | بهبود ۸٪ | EMS | ماهانه |
| تلفات هوای فشرده | `(تولید − مصرف اندازه‌گیری‌شده) / تولید × 100` | ≤ ۱۰٪ | فلومترها | فصلی |
| آمادگی تأسیسات | `زمان در دسترس‌بودن خدمت / زمان مورد نیاز × 100` | ≥ ۹۹٪ | CMMS | ماهانه |
| زمان پاسخ به خرابی تأسیسات | `AVG(زمان شروع تعمیر - بروز خرابی)` | ≤ ۳۰ min | CMMS | ماهانه |
| انطباق زیست‌محیطی | `تعداد روزهای خارج از حد مجاز` | ۰ | آنالایزر + HSE | ماهانه |
| درصد PM تأسیسات به‌موقع | `PM به‌موقع / برنامه × 100` | ≥ ۹۵٪ | CMMS | ماهانه |
| تعداد توقف‌های تولید ناشی از تأسیسات | `COUNT` | کاهش ۵۰٪ | MES + CMMS | ماهانه |
