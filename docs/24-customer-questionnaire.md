# ۲۴. پرسش‌نامهٔ شفاف‌سازی برای مشتری (برای تکمیل)

> این فرم از `data/open_questions.csv` تولید می‌شود تا همواره با مستند ۱۶ هم‌خوان باشد.
> لطفاً ستون «پاسخ شما» را تکمیل کنید و پرونده را برای تیم پروژه بازگردانید.
> هر پاسخ، یک «[فرض]» را به واقعیتِ مستند تبدیل می‌کند و دقت برآوردها را بالا می‌برد.

**راهنمای تکمیل:**

- پرسش‌های 🔴 **بلوکه‌کننده**اند: پیش از آغاز فاز ۰ یا ۱ باید پاسخ داده شوند.
- اگر پاسخ را نمی‌دانید، عبارت «نامشخص» را بنویسید — این صادقانه‌تر از حدس‌زدن است؛
  تیم پروژه برای هر «نامشخص» یک روشِ اندازه‌گیری پیشنهاد می‌دهد.
- هرجا عدد می‌دهید، **منبع عدد** را هم بنویسید (سیستم، گزارش، تخمینِ خبره).
