# ۱۲. تحلیل ریسک و برنامهٔ کاهش (Risk Register)

## ۱۲-۱. روش ارزیابی

```
امتیاز ریسک = احتمال (۱ تا ۵) × اثر (۱ تا ۵)
  ۱–۴   کم       (سبز)   — پایش دوره‌ای
  ۵–۹   متوسط    (زرد)   — برنامهٔ کاهش فعال
  ۱۰–۱۴ بالا     (نارنجی)— اقدام فوری + گزارش ماهانه به کمیتهٔ راهبری
  ۱۵–۲۵ بحرانی   (قرمز)  — اقدام فوری + مالک در سطح مدیرعامل + هشدار در صورت عدم پیشرفت
```

| اثر / احتمال | ۱ بسیار کم | ۲ کم | ۳ متوسط | ۴ زیاد | ۵ تقریباً قطعی |
|---|---|---|---|---|---|
| **۵ فاجعه‌بار** | ۵ | ۱۰ | ۱۵ | ۲۰ | ۲۵ |
| **۴ بحرانی** | ۴ | ۸ | ۱۲ | ۱۶ | ۲۰ |
| **۳ متوسط** | ۳ | ۶ | ۹ | ۱۲ | ۱۵ |
| **۲ جزئی** | ۲ | ۴ | ۶ | ۸ | ۱۰ |
| **۱ ناچیز** | ۱ | ۲ | ۳ | ۴ | ۵ |

## ۱۲-۴. برنامهٔ کاهشِ سطح‌بالا (Risk Response Plan)

| دستهٔ ریسک | راهبرد غالب | اقدامات کلیدی |
|---|---|---|
| داده (R01, R05, R10) | **کاهش + پیشگیری** | حاکمیت دادهٔ پایه از فاز ۰؛ لایهٔ معنایی یگانه؛ مانور دوره‌ای ردیابی |
| فنی/یکپارچه‌سازی (R02, R03, R07, R08) | **کاهش** | معماری رویدادمحور با idempotency؛ قراردادهای نسخه‌دار؛ HA/DR؛ ارزیابی زودهنگام |
| امنیت (R06, R20) | **کاهش + انتقال** | زون/کاندویت، MFA، پایش پیوسته، بیمهٔ سایبری |
| تغییر و انسانی (R04, R11, R12) | **کاهش + پذیرشِ مدیریت‌شده** | مدیریت تغییر ساختاریافته، آموزش، رهبران تغییر، شاخص ثبت دستی |
| عملیاتی (R17, R18) | **کاهش** | نصب در پنجره‌های توقف، کنترل تغییر رسمی، سناریوی بازگشت |
| تأمین و قانونی (R13, R14, R19) | **پذیرش + کاهش** | لایهٔ آداپتور، چندمنبعی، ذخیرهٔ احتیاطی |
| قراردادی (R16) | **انتقال + کاهش** | تعهدات قراردادی انتقال دانش، مستندسازی به‌عنوان پیش‌شرط پرداخت |
