# ۶. فهرست تجهیزات و حسگرهای پیشنهادی

> این مستند «فهرست خریدِ اولیه» است؛ جزئیات هر واحد در [`03-units/`](03-units/) آمده است.
> اعداد [فرض] هستند و پس از ممیزی فنی (فاز ۰) باید قطعی شوند.

## ۶-۱. خلاصهٔ حجم تجهیزات بر حسب واحد

| واحد | گروه‌های اصلی تجهیزات | شمار تقریبی نقطه/دستگاه [فرض] | سهم از بودجهٔ سخت‌افزار |
|---|---|---|---|
| حراست (SEC) | کارت‌خوان/چهره، گیت مانع، ANPR، دوربین IP، NVR، باسکول، سنسور درب | ~۱۳۰ | ۱۰٪ |
| HSE | دتکتور گاز ثابت/پرتابل، پنل اعلام حریق، ایستگاه‌های اضطراری، پایش محیطی، تبلت ATEX | ~۵۹۰ | ۱۳٪ |
| تولید و QC (PRD/QCL) | PLC/HMI، بارکدخوان، ترازو، ابزار دقیق فرآیندی، بینایی ماشین، تبلت خط، چاپگر لیبل، شبکه | ~۴۰۰ | ۳۰٪ |
| انبار فنی (MRO) | بارکدخوان، RFID (اختیاری)، ترمینال لیفتراک، قفسه‌بندی | ~۳۰ | ۳٪ |
| انبار مواد (RMW) | باسکول، ترازو، بارکدخوان، سنسور دما/رطوبت، ترمینال لیفتراک | ~۶۵ | ۶٪ |
| انبار محصول (FGW) | بارکدخوان ثابت/دستی، دروازهٔ RFID، ترازوی پالت، چاپگر لیبل، دیتالاگر حمل | ~۹۰ | ۷٪ |
| نگهداشت (MNT) | سنسور لرزش، دما، کیت روغن، برچسب QR/RFID دارایی، تبلت تکنسین | ~۸۷۰ (عمدتاً برچسب/نقاط) | ۱۵٪ |
| برق (ELE) | پاورمتر، رله حفاظتی، CT/PT، سنسور دمای تابلو، ترموگراف، مانیتور باتری | ~۴۵۰ | ۹٪ |
| مکانیک (MEC) | سنسور لرزش، دما، فشار روغن، روانکاری خودکار، ابزار تراز/بالانس | ~۲۳۰ | ۵٪ |
| تأسیسات (UTL) | ترانسمیتر دما/فشار/دبی/سطح، آنالایزر کیفیت آب، دیوپوینت، کنتور، VFD، آنالایزر پساب | ~۲۳۰ | ۱۲٪ |

## ۶-۲. اصول مشترک انتخاب سخت‌افزار

| اصل | الزام | دلیل |
|---|---|---|
| **باز بودن (Open)** | OPC UA، ONVIF، Modbus TCP، MQTT — پروتکل اختصاصیِ بسته ممنوع مگر با gateway | جلوگیری از قفل‌شدن به تأمین‌کننده (Vendor Lock-in) |
| **تشخیص‌پذیری (Diagnostics)** | خروجی وضعیت سلامت خودِ دستگاه | یک حسگرِ خرابِ خاموش، بدتر از نبود حسگر است |
| **مناسب محیط** | IP66 در سوله، ضد انفجار (ATEX/IECEx) در مناطق خطر، مقاوم به شست‌وشو (CIP/SIP) | کاهش خرابی و توقف |
| **تأمین برق و شبکه** | PoE+ باتشریک، UPS برای تجهیزات حفاظتی، افزونگی مسیر | پایداری در قطع برق |
| **کالیبراسیون** | امکان کالیبراسیون آسان + ثبت در CMMS | انطباق ISO/HACCP |
| **مدیریت چرخهٔ عمر** | تأمین‌کننده متعهد به حداقل ۷ سال پشتیبانی قطعات | جلوگیری از تکرار بحران S7-300 |
| **امنیت** | تغییر رمز پیش‌فرض، به‌روزرسانی firmware، غیرفعال‌سازی پورت‌های بلااستفاده | الزام IEC 62443 |

## ۶-۳. استانداردهای مرجع نصب و بهره‌برداری

| حوزه | مرجع |
|---|---|
| ابزار دقیق فرآیندی | IEC 61511 (SIL)، ISA-5.1 (نمادگذاری)، ISA-75/76 |
| لرزش و پایش وضعیت | ISO 20816، ISO 13373، ISO 18436 |
| برق و کیفیت توان | IEC 61439، IEEE 519، IEC 61850 (در صورت پست دیجیتال) |
| حریق و گاز | ISO 7240، IEC 60079 (مناطق انفجاری)، EN 45545 در صورت نیاز |
| ویدئو و تردد | ONVIF Profile T/S، IEC 62676 |
| شناسایی و ردیابی | GS1 (GTIN، SSCC، GLN، EPCIS)، ISO/IEC 15459 |
| شبکهٔ صنعتی | IEC 62443-3-3، ANSI/TIA-1005 (کابل‌کشی صنعتی) |

## ۶-۴. ردیف‌های هزینه‌ای که معمولاً فراموش می‌شوند

| ردیف | چرا مهم است |
|---|---|
| کابل‌کشی، داکت، ترانکینگ و براکت نصب | معمولاً ۱۰–۱۵٪ هزینهٔ تجهیزات است و در برآوردها جا می‌ماند |
| کالیبراسیون اولیهٔ ابزار دقیق | بدون آن دادهٔ اولیه غیرقابل‌اعتماد است |
| قطعات یدکیِ خودِ تجهیزات جدید | برای ۲ سال نخست (مثلاً ۱۰٪ تعداد هر نوع حسگر) |
| ابزار و تجهیزات تست (کالیبراتور، آنالایزر) | الزام نگهداشت و انطباق |
| پوشش بی‌سیم (Site Survey + APها) | پرهزینه‌ترین موردِ «پنهان» در سوله |
| آموزش نصابان و بهره‌برداران | نقص نصب عامل اصلی خرابی‌های زودهنگام |
| لایسنس نرم‌افزار (Historian tag count، دوربین، کلاینت) | باید پیش از خرید با رشد ۳ ساله دیده شود |
